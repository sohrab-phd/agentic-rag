## Recommended production change

### 1. Bypass aggregate_answers when there is exactly one grounded sub-answer and rewrite produced a single intent
- **Pass-rate improvement:** Low–medium (prevents corruption on single-answer flows)
- **Latency reduction:** ~10.14s per single-intent query (13.4% of pipeline)
- **Risk:** Low
- **Evidence:** 1 single-answer runs altered by aggregation; 1 failures introduced

### 2. For multi-intent, use deterministic merge template before optional light aggregation
- **Pass-rate improvement:** Medium if multi-intent information loss detected
- **Latency reduction:** Partial aggregation skip
- **Risk:** Medium
- **Evidence:** 1 multi-intent items; information loss rate 0.033

### 3. Tighten aggregation prompt to forbid dropping any sub-answer facts; require per-part coverage
- **Pass-rate improvement:** Low
- **Latency reduction:** None
- **Risk:** Low
- **Evidence:** Prompt-only; does not remove aggregation LLM call
